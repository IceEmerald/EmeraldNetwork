Start here

What EmeraldNetwork is, and how this wiki is organised.

Everything here runs in your browser. There is no account to create, nothing to install, and no server holding your work — notes, documents, decks, spreadsheets and chats are written straight into this browser's storage. Open a page, start typing, and it is saved.

That one decision shapes everything else. Because your files never travel, they also never follow you: a different browser, a different device, or a cleared cache starts from an empty library. In exchange there is nothing to leak, nothing to lose to a bad login, and nothing to pay for. Each app below tells you what it can export, so keep a copy of anything you care about.

Before you start

Export before you clear anything. Each app has its own export — Notes as a share link, Docs as PDF/HTML/TXT, Slides as PPTX/PDF/SVG, Sheets as XLSX/CSV, chats as a link, flowcharts as .emeraldcore. Clearing browsing data wipes the library with no way back.
The AI chat is the exception. Everything else works offline once loaded. Chat and live voice send what you type to a hosted model, and the Discord bot lives on Discord's servers. See Shared reference for exactly what leaves your device and what does not.

The hub

One home for every note, document, presentation and spreadsheet you create.

The hub is the answer to "where did I put that?". It reads the index of all four apps out of shared storage and renders one combined library, so a note written this morning and a spreadsheet from last week sit in the same list.

It does not hold anything itself. Renaming or deleting here reaches into the app that owns the file, so the two never disagree.

Finding and tidying your files

  1. Open /emeraldsuite. Anything you have created appears under Your files.
  2. Filter with Notes, Documents, Presentations or Spreadsheets. Filters combine — pick two to narrow further.
  3. Type in Search your files… to match on the title. Recent files and the quick-create tiles collapse so results sit higher up.
  4. Sort by Recently edited, Name (A–Z) or Name (Z–A).
  5. Hover a card for Open, Rename and Delete, or right-click for the full menu including Copy link.
  6. Click the storage icon in the top bar to see how much of your browser quota is in use.

Storage meter

The database icon in the top bar opens a Storage popup with Used, Available, a proportional bar and a percentage line. It reads the browser's own quota via the Storage API, so the number reflects your whole origin, not just the suite. Browsers that do not expose a quota show Storage estimate unavailable in this browser.

The hub does not break usage down per app. The AI chat's Settings dialog is the only place that itemises storage.

Keeping the hub in sync

  • Open the same app in two tabs and edits propagate both ways through a browser broadcast channel.
  • The hub refreshes on window focus, on tab visibility change, on load, and every 60 seconds.
  • Renaming or deleting in the hub updates the real document, not just the list entry.

EmeraldNotes

Rich text notes with tables, to-do lists, drawing, images and live collaboration.

Notes is the app you will open most often, because it is the one that asks for no decisions. No layout, no styles to choose, no page setup — open it and type. The formatting is there when you want it and invisible when you do not.

It is also the only app with live collaboration, so a note is the quickest thing to actually share with someone rather than just hand over a file.

A note from empty to shared

  1. Open /notes and press Ctrl+N, or click New Note in the sidebar.
  2. Type a title, then start writing underneath it. Everything saves on its own — there is no save button to press.
  3. Use the ribbon when you need structure: Table for a grid, To-Do for a checklist, Image for a screenshot.
  4. Press Ctrl+F to find and replace something you wrote earlier.
  5. Click Share Note, choose Can edit or Can view, and copy the link.
  6. Open that link in a second tab. Typing in either one appears in the other, with the other person's cursor visible.

Tables

  1. Click Table in the ribbon and pick a size from the grid (up to 8 × 8). The first row becomes a header row.
  2. Click any cell to reveal the floating table toolbar above the table.
  3. Use Add Row Above / Add Row Below / Delete Row and Add Column Left / Add Column Right / Delete Column.
  4. Drag the right edge of a column to resize it (minimum 40px). Widths are saved with the note.

Deleting the last row removes the whole table. Deleting the last column does nothing, so you cannot accidentally destroy a table.

To-do lists

  1. Click To-Do to drop in a checkbox item.
  2. Type the text next to the checkbox.
  3. Press Enter for another item, Tab to indent it, Shift+Tab to outdent.

Drawing

  1. Click Draw in the ribbon. A toolbar appears with Pen, Eraser, nine colours and four sizes — Thin, Medium, Thick, Extra Thick.
  2. Drag on the page to draw. Use Move to reposition the drawing or the corner handle to resize it.
  3. Clear wipes the canvas if you want to start over.
  4. Click ✓ Done. The drawing is cropped to its content, saved as a PNG and placed into the note as an image.

Drawings become part of the note, so they show up in shared links and exports like any other image.

Images

  • Insert → Image opens your file picker, and you can also drag image files straight onto the editor or paste one from the clipboard.
  • Maximum size is 25 MB per image.
  • Click an image to select it; a corner handle resizes it with the aspect ratio locked.
  • Images are stored inline, so they travel with the note and count towards your storage quota.

Sharing a note

Export as link

Export Note packs the title, content and colour into a compressed token and gives you a URL. Anyone who opens it gets their own copy added to their library. Nothing is uploaded.

Live collaboration

Share Note opens a real-time session. Choose Can edit or Can view, copy the collaboration link and share it. You can watch who is in the session and close it at any time.

Live sharing needs an internet connection, and both of you have to be online at the same time — it is a session between two open browsers, not a file that gets handed over. Export Note has neither requirement: the whole note is encoded in the link, so you can share it from an offline tab and the other person reads it whenever they like. Everything in Notes except live sharing works without a connection.

A shared link stops working once the document gets long — very large notes exceed what a browser will hold in a URL and the export says This note is too long to share with a link. You can take part in one live session at a time; leave the current one before joining another.

Autosave, undo and limits

  • Autosave runs one second after you stop typing; Ctrl+S forces it.
  • Undo history is the browser's own, so it is per-note and is lost when you close the note.
  • Notes have no folders and cannot be reordered — the list is newest first.
  • Everything works offline once the page is loaded; only collaboration and web fonts need a connection.

EmeraldDocs

A word processor that paginates, references, comments and PDF export.

Docs is the app to reach for when the output is going to be read rather than glanced at. It paginates your content into pages with margins, which is what makes the table of contents, footnotes and PDF export behave the way a reader expects.

Real pagination

Docs is not one long scrolling page — it lays your content out across actual page sheets (A4 by default). Blocks move between pages as you type, and a paragraph that is too tall for the remaining space is split at a word boundary rather than mid-word. Inserted page breaks force a hard boundary.

Autosave, links and limits

  • Autosave runs about 0.8 seconds after you stop typing; the pill says Saving…, then All changes saved.

EmeraldSlides

Presentations with 65 shapes, 37 transitions, animations, notes and PowerPoint export.

Slides is built around the last five minutes of making a deck: putting it in front of people. That is why transitions, animations and presenter notes are first-class here, rather than the kind of thing you add afterwards in another tool.

It imports and exports PowerPoint files, so a deck can start here and finish somewhere else without being flattened into pictures.

Empty deck to a presented one

  1. Open /slides and click Create New Presentation, or the ribbon's New.
  2. Go to Design and pick a theme — it applies to every slide at once, so start here rather than restyling later.
  3. Add text with Insert → Text, then click an element once to select it and twice to edit its words.
  4. Switch to View → Slide Sorter to see the whole deck at once. Drag thumbnails to reorder.
  5. Open Notes Page and write what you want to say for each slide. The notes stay with the deck.
  6. Apply a transition from the Transitions tab, set it to advance after a delay, then Apply to All.
  7. Press F5 to present from the current slide, or F11 from the beginning.

EmeraldStudio Flowchart

A visual programming environment — build an algorithm from shapes, then run, step and debug it.

Flowchart is a programming environment you build by drawing. Statements are shapes, connections are the flow, and you watch the program run through the same canvas — which makes it a direct way to see what code is doing, and to teach logic to someone who has never written any.

The language is Flowgorithm-compatible, so expressions such as ^, mod, div and and/or/not behave the way you would expect from elsewhere.

Your first program, end to end

  1. Open /flowchart. A starter template is already on the canvas: Start → Output "Hello" → End.
  2. Press Run. Hello appears in the Console — that is the whole loop working.
  3. Click Input in the palette, then drag it onto the canvas. Its dialog asks which variable receives the value.
  4. Add a Declare shape above it and set the name to match, with type Integer. Nothing runs until a variable is declared.
  5. Drag from the bottom handle of one shape onto the next to connect them.
  6. Add an If shape. It has two handles: T on the left for true and F on the right for false.
  7. Press Step instead of Run. One shape executes per press and the Variables panel shows every value as it changes.
  8. When something misbehaves, drop a Breakpoint on the path and step through again.

Build a program in 5 steps

  1. Click or drag a shape from the Statements palette on the left onto the canvas.
  2. Double-click the shape (or select it and press Enter) to set its properties.
  3. Drag from a green connection handle onto another shape to wire them together. Branching shapes get a T handle and an F handle.
  4. Press Run to execute, or Step to advance one shape at a time.
  5. Watch the Console for output and the Variables panel for live values.

A brand-new canvas starts with the classic Start → Output "Hello" → End template, so you can hit Run immediately.

  3. e!log enable #mod-log — so deletions are recorded.
  4. e!chatlock in #announcements whenever you post something important.

Quieting a channel

  1. e!chatlock to freeze the channel.
  2. e!purge 50 to clear the spam.
  3. e!mute @user spamming for the people behind it.
  4. e!banworduser @user spamword if it is one specific phrase.
  5. e!chatlock again to reopen.

A music room

  1. Join a voice channel and invite EmeraldBot.
  2. e!play lofi hip hop — or paste a link.
  3. e!queue to see what is lined up, e!skip to move on, e!repeat all to loop the queue.
  4. e!nowplaying shows the current track; e!stop clears everything when the night is over.

A birthday channel

  1. Members run e!setbirthday dd/mm privately.
  2. Anyone can run e!nextbirthday to see who is next.
  3. Moderators use e!banwordlist and e!resetai if someone wants their stored data removed.

Permissions

The bot asks for a broad permission set when you invite it, because music playback needs Connect and Speak in voice, moderation needs Manage Messages and Manage Roles, and logging needs Manage Channels. Restrict the bot's role to the channels it actually needs and put it above your member roles so it can act.

Invite the bot from the bot page, or ask in the EmeraldNetwork Discord server if something looks wrong.

EmeraldEssentials

A Minecraft server plugin suite. Not documented yet — and that is deliberate.

No command list or config reference here. The plugin is not feature-complete, so publishing one would mean inventing it. Below is everything that is actually known today.

What it is

EmeraldEssentials is a plugin suite for Minecraft servers, positioned around two ideas: wide compatibility — working across server platforms and alongside other plugins rather than fighting them — and stability, keeping a busy server running smoothly. It follows the same visual identity as the rest of EmeraldNetwork, but it is a completely separate product from the browser apps.

Not available yet

  • No command list — nothing to document until the command surface is settled.
  • No config.yml reference, because the config format is still changing.
  • No permissions node table, and no supported-version range.
  • No installation walkthrough — there is nothing public to download yet.

Getting it

Access is by direct contact rather than a public download. Ask in the EmeraldNetwork Discord server and you will be told whether the plugin is ready for your server version and how to get it.

The other three products are documented in full: EmeraldSuite for documents and spreadsheets, EmeraldStudio Flowchart for visual programming, and EmeraldBot for Discord.

Where your files are stored

Every app writes to IndexedDB in this browser. Notes, Docs, Slides and the AI chat share one database, emeraldcore.storage.suite, which is why the suite hub can list all of them. Sheets keeps its own, emeraldcore.storage.suite.sheets, because workbooks are structured differently.

Notes, Docs, Slides and the chat also drop a temporary copy into localStorage while a write is in flight and delete it afterwards, so a long note is never half-written.

There is no server-side copy of anything. Clearing browsing data, using a different browser, switching to a private window, or reinstalling means an empty library, permanently. Export before you do any of those things — and export periodically if the work matters.

Multiple tabs and windows

Apps talk to each other through a browser broadcast channel, so you can have the same note open twice and see edits land in both. The hub refreshes on window focus, when the tab becomes visible again, and every 60 seconds.

What leaves your device

Worth stating plainly, since almost nothing is sent anywhere.

  • The four office apps, Flowchart and the hub send nothing. They never touch a network after the page loads.
  • AI chat sends what you type, plus your display name, your saved memories and any file you attach.
  • Live voice sends audio, the same name and memories.
  • Share links pack the data into the part of the URL after the #, which browsers never send to a server. Nothing is uploaded.
  • The Discord bot runs on Discord and sees what a bot normally sees.
  • No analytics, no tracking script, no API key in the page, no account.
